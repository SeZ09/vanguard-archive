# vanguard-archive
**[Try Vanguard Archive 8.12.3 Live at vgdarc.com](https://vgdarc.com)**

Vanguard Archive is a portable, single-file game collection/backlog manager that runs entirely in your browser. It lets you organize your library with custom statuses (like "Backlog" or "Completed"), track release years and genres, and generate visual stats about your gaming habits, all without needing an internet connection or a dedicated app.

## Interface & Views
Vanguard Archive offers multiple ways to view your collection. The **Grid View** provides a visually rich, card-based layout highlighting cover art, active statuses, and your custom medal ratings.

![grid view](pictures/vgdarc01.png "grid view using the rose theme")

For a denser, more analytical look at your library, toggle to the **List View**. This layout prioritizes readability, making it easy to scan through titles, platforms, completion metrics, and scores at a glance.

![list view](https://github.com/SeZ09/vanguard-archive/blob/main/pictures/vgdarc2.png "list view using the emerald theme")

## Power of Filtering & Sorting

Find exactly what you're looking for in seconds. The dynamic filter drawer automatically populates with the platforms, genres, and statuses currently in your library. Combine these tags with the flexible sorting menu to organize your collection by release year, rating, or even time-to-beat.

![filtering](https://github.com/SeZ09/vanguard-archive/blob/main/pictures/vgdarc4.png "filtering using the slate theme")

## Comprehensive Statistics

Keep track of your gaming habits with the built-in Statistics Dashboard. Instantly view your overall completion rate, total backlog hours, average library scores, and a visual breakdown of your most-played genres to see where your time is going.

![statistics](https://github.com/SeZ09/vanguard-archive/blob/main/pictures/vgdarc3.png "statistics using the azure theme")

## Deep Customization & Easy to Add Metadata

Managing your collection should be as satisfying as playing it. Use the 'Auto-Fetch' tool to instantly pull high-quality vertical cover art, how long to beat information, genre and metacritcs score of the selected game in the selected console/pc then dive into the tabbed editor to log playtimes, track custom achievements, assign subjective vibes, and fine-tune your rating using the custom objective sliders.

![adding game information](https://github.com/SeZ09/vanguard-archive/blob/main/pictures/vgdarc0.png "game data using the rose theme")
